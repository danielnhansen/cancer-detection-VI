
## ODELIA Challenge Dataset

This dataset is part of the [ODELIA project](https://odelia.ai/), a European Horizon initiative focused on developing privacy-preserving, AI-driven diagnostic tools using swarm learning.

The dataset provided here represents a curated subset of data from the broader ODELIA consortium. It is designed to facilitate the development, benchmarking, and validation of AI algorithms that can operate effectively across a range of heterogeneous clinical settings.

The dataset contains breast MR images along with corresponding lesion labels. For a comprehensive description of the dataset and its intended use, please refer to our paper: [Read the paper](https://arxiv.org/abs/2506.00474)
